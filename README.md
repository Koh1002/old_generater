# AgeShift Story

顔写真から年齢を変換し、その年齢での「生活の様子」と「性格」を小説風の登場人物紹介文として生成するWebアプリケーションです。

## 機能

- 📸 **顔写真のアップロード** - ドラッグ&ドロップまたはクリックでアップロード
- 🎭 **年齢変換画像生成** - 指定した年齢の顔画像を生成
- 📝 **小説風キャラクター紹介** - 生活の様子と性格を自動生成
- 🔐 **安全なAPI管理** - APIキーはサーバー側のみで使用、保存されません
- 🚫 **未成年保護** - 18歳未満の年齢変換はブロック
- 🤖 **複数AIプロバイダー対応** - OpenAI と Gemini をサポート

## 技術スタック

- **フロントエンド**: Next.js 14 (App Router) + TypeScript + Tailwind CSS
- **バックエンド**: Next.js API Routes
- **AI Provider**: OpenAI API / Google Gemini API
- **画像処理**: Sharp

## セットアップ

### 必要な環境

- Node.js 18.0.0 以上
- npm または yarn

### インストール

1. リポジトリをクローン

```bash
git clone <repository-url>
cd old_generater
```

2. 依存関係をインストール

```bash
npm install
```

3. 環境変数を設定（オプション）

```bash
cp .env.example .env
```

`.env` ファイルを編集:

```env
PORT=3000
DEBUG_SAVE_UPLOADS=false  # true にすると ./tmp/uploads に画像を保存
```

**注意**: APIキーは環境変数ではなく、UI上で入力します。

### 開発サーバーの起動

```bash
npm run dev
```

ブラウザで http://localhost:3000 を開きます。

### ビルドと本番起動

```bash
npm run build
npm start
```

## 使い方

1. **AIプロバイダーを選択**
   - OpenAI または Gemini を選択

2. **APIキーを入力**
   - OpenAI: https://platform.openai.com/api-keys で取得
   - Gemini: https://makersuite.google.com/app/apikey で取得
   - 「接続テスト」ボタンで接続を確認

3. **顔写真をアップロード**
   - JPEG、PNG、WebP形式（最大10MB）
   - ドラッグ&ドロップまたはクリックでアップロード

4. **年齢を入力**
   - 写真時の年齢: 写真が撮影された時の年齢（18歳以上）
   - ターゲット年齢: 生成したい年齢（18歳以上）

5. **生成ボタンをクリック**
   - 生成には30〜60秒かかる場合があります
   - 生成結果は最大3件まで画面に保持されます

6. **結果を確認**
   - 生成画像をクリックすると拡大表示
   - 「コピー」ボタンで紹介文をクリップボードにコピー

## 制限事項

### 年齢制限

- **18歳未満の年齢変換は扱いません**
- 写真時の年齢、ターゲット年齢ともに18歳以上である必要があります
- この制限は安全性と法的配慮のために設けられています

### 画像制限

- ファイル形式: JPEG、PNG、WebP
- ファイルサイズ: 最大10MB
- 推奨: 顔がはっきり写っている正面または斜め顔の写真

### 生成時間

- OpenAI DALL-E: 20〜40秒程度
- Gemini: 30〜60秒程度（モデルにより異なる）
- ネットワーク状況により変動します

### API制限

- 各プロバイダーのレート制限に従います
- APIキーの利用枠を超えた場合はエラーが表示されます

## セキュリティとプライバシー

### APIキーの取り扱い

- ✅ APIキーはUI入力のみ（環境変数に保存しない）
- ✅ サーバー側でのみ使用
- ✅ リクエスト処理中のメモリ上にのみ保持
- ✅ データベースやログに保存されません
- ✅ ブラウザに送信されません

### 画像の取り扱い

- アップロード画像は **メモリ上で処理**
- デフォルトではディスクに保存されません
- `DEBUG_SAVE_UPLOADS=true` の時のみ `./tmp/uploads` に保存（開発用）
- ページをリロードすると生成結果は消えます

### 本番運用時の注意

本番環境で運用する場合は、以下を必ず実施してください：

1. **HTTPS必須**
   - APIキーを安全に送信するためHTTPSを使用
   - Let's Encrypt などで無料のSSL証明書を取得

2. **環境変数管理**
   - `DEBUG_SAVE_UPLOADS` は必ず `false` に設定

3. **レート制限**
   - プロバイダーのレート制限を考慮
   - 必要に応じてサーバー側でレート制限を実装

4. **ログ管理**
   - APIキーがログに出力されないことを確認
   - 本番環境では適切なログレベルを設定

5. **エラーハンドリング**
   - ユーザーに詳細なエラー情報を返さない
   - 内部エラーは適切にログに記録

## トラブルシューティング

### APIキーが無効と表示される

- APIキーが正しいことを確認
- プロバイダー選択が正しいか確認（OpenAI/Gemini）
- APIキーの利用枠が残っているか確認

### 画像生成が失敗する

- 顔写真が明瞭かつ正面に近いか確認
- ファイルサイズが10MB以下か確認
- ネットワーク接続を確認

### Gemini で画像生成ができない

- 現在、Gemini の画像生成機能は開発中です
- OpenAI プロバイダーをご利用ください
- Gemini API の画像生成機能が正式リリースされ次第対応予定

### 生成に時間がかかりすぎる

- 初回生成時はモデルの読み込みに時間がかかることがあります
- ネットワーク速度を確認してください
- プロバイダーのステータスページを確認してください
